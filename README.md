# Epsilon Web — نظام إبسيلون الداخلي (مبيعات / مخزون / حسابات / CRM)

## بنية المشروع
```
epsilon-web-project/
├── index.html        ← الصفحة الرئيسية (هيكل الواجهة)
├── css/
│   └── style.css     ← كل التنسيقات والألوان
├── js/
│   └── app.js        ← كل منطق النظام (الحفظ في localStorage)
└── assets/           ← الصور والملفات الثابتة
```

## التشغيل
- الطريقة الأسهل: افتح الفولدر في VS Code (File → Open Folder)،
  وبعدين كليك يمين على index.html واختر "Open with Live Server".
- أو شغّل أي خادم ثابت بسيط من داخل الفولدر، مثال:
  `npx serve .` أو `python -m http.server`

## ملحوظات
- البيانات تُحفظ في متصفح المستخدم (localStorage) على نفس الجهاز.
- من داخل النظام: تصدير/استيراد نسخة احتياطية JSON من الإعدادات.
